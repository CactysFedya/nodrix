# Security policy

## Supported versions

Security fixes are provided for the latest Plyctl 2.x release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability involving network parsing, authentication, package extraction, native plugin loading, shared memory, or secret disclosure.

Use GitHub private vulnerability reporting for `CactysFedya/plyctl`. Include a minimal reproduction, affected version, impact, and suggested mitigation when available.

Never attach live credentials, stream tokens, private recordings, or unredacted `.nodrix/runs` artifacts.
