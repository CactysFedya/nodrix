# Nodrix

Nodrix is a high-performance typed runtime for local and distributed streaming graphs. Version 1.0 stabilizes the Python SDK and C++ Plugin ABI and adds packages, reproducible locks, lifecycle/health, secure streams, metrics and production run artifacts.

```bash
nodrix init my-project
nodrix init camera-app --template vision
nodrix validate --strict
nodrix lock
nodrix run --locked
```

Start with [Full Workflow](Full-Workflow) or [Production Runtime](Production-Runtime).

Compact manifests, performance profiles and per-node CPU/RAM telemetry are available in Nodrix 1.1.
