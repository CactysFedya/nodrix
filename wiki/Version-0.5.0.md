# Nodrix 0.5.0

Версия 0.5.0 переводит проект от CV-специфичного прототипа к универсальному
runtime.

Основные изменения:

- только команда `nodrix`;
- `Node` вместо отдельного `FastNode`;
- заполненные шаблоны `init`;
- Core и Vision SDK;
- именованные сетевые streams;
- multicast discovery по всем IPv4-интерфейсам;
- прямое peer-to-peer соединение;
- генератор Python/C++ типов;
- C++ plugin ABI 2.

Подробности находятся в `docs/RELEASE_0.5.0.md`.
