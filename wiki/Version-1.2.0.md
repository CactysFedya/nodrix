# Nodrix 1.2.0

Reusable YAML Blocks:

- `blocks:` in compact manifests;
- `--block name=path.yaml` replacement;
- short `--set detector.conf=value` paths;
- `nodrix block list` and `nodrix block inspect`;
- imported block checksums in `nodrix.lock`;
- no runtime overhead or new execution boundary.

See `docs/RELEASE_1.2.0.md` and `docs/BLOCKS.md` in the repository.
