# Заметки к выпуску

## Plyctl 2.2.0 alpha.5

На сайте описывается только текущая версия. Предыдущие изменения сохраняются в
`CHANGELOG.md` и GitHub Releases.

### Основные изменения

- основной CLI и Python SDK переименованы в `plyctl` с совместимыми псевдонимами `nodrix`;
- Python, C++, ROS 2, процессы, устройства и транспорты работают в одном Manifest v2;
- Spatial, Mapping, ROS 2 и Spatial ROS 2 устанавливаются отдельными пакетами;
- Provider API 1 проверяет метаданные, совместимость и подписи до импорта кода;
- добавлен production-блок NCNN через Plugin C ABI 2;
- документация публикуется на английском и русском языках.

### Миграция

Старые `nodrix.dev/v1` и `nodrix.dev/v2` продолжают работать. Команда
`plyctl migrate` нужна для перехода на канонические имена, а не для срочного
исправления совместимости.
