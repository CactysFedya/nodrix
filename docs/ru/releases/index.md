# Текущий релиз: 2.3.0 alpha 1

Сайт соответствует ветке `feature/2.3.0-workspace-and-operations` и версии `2.3.0a1`.

## Основные изменения

- Workspace и поиск project вверх по каталогам.
- Pipeline aliases и named contexts.
- Setup scripts, variables и preflight checks.
- Hardware/runtime profiles и operator views.
- Команды `workspace`, `context`, `env`, `use`, `prepare`, `shell`.
- `up`, `down`, `restart`, `ps`, `logs`.
- Views `compact`, `operations`, `debug`.
- Метрики managed ROS 2 processes.
- Интеграция FAST-LIO2 и RViz.
- Provider APIs 1/2 и Plyctl compatibility naming.

Это alpha-версия. Фиксируйте exact version/commit и проверяйте manifests в CI.

Полная история должна находиться в `CHANGELOG.md` и GitHub Releases, а не в основном меню документации.
