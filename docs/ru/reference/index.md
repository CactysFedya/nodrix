# Справочник

## Основные команды

| Команда | Назначение |
|---|---|
| `plyctl init` | создать проект из шаблона |
| `plyctl validate` | проверить манифест и контракты |
| `plyctl inspect` | показать разрешённый граф и план |
| `plyctl run` | запустить pipeline |
| `plyctl top` | показать состояние и ресурсы |
| `plyctl provider list` | показать доступные провайдеры |
| `plyctl doctor` | проверить окружение и интеграции |
| `plyctl migrate` | переписать старый манифест в актуальный формат |
| `plyctl schema` | создать JSON Schema для редактора |

Полный API-справочник пока публикуется в английской версии. При переходе с
глубокой английской страницы переключатель откроет главную страницу русского
раздела, если перевода ещё нет.
