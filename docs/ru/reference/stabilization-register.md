# Реестр стабилизации 2.3 beta

Реестр отделяет выполненные изменения от backlog. Release notes не должны
описывать запланированную возможность как уже реализованную.

## Выполнено в 2.3.0b1

- Стабильная identity локальных file modules и regression tests.
- Единая release metadata и исправленные repository URLs.
- Двуязычные principles, release, deployment и integration guides.
- Проверка критических страниц документации.
- Честно зафиксированный Raspberry Pi 5 hardware smoke.

## Release blockers

- Корректный ненулевой semantic object output.
- Подтверждённое сохранение metric map.
- Диагностика дублирующихся Livox processes.
- Чистый process-group shutdown и повторный restart.
- Endurance evidence и измерения производительности.

## Backlog Operations

- Изоляция toolchain и virtual environment.
- Live logs долгих build.
- Source manager и source lock.
- Resource-aware compilation.
- Patch manager.
- Статическая проверка ROS packages, executables, launch files и libraries.
- Process-tree CPU/RSS и классификация shutdown.
- Default environment и project discovery.
- Shell completion.
- Встроенный stream inspection или поставляемый viewer.

## Backlog документации

- Генерируемый CLI и schema reference.
- Полный Python Node SDK tutorial.
- Provider Developer Kit tutorial.
- Native plugin tutorial.
- Проверенная offline bundle инструкция.
- Capability и performance matrix.
- Troubleshooting по фактическим qualification failures.
