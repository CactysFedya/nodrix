# Концепции

## Pipeline OS

Plyctl описывает вычислительную систему как типизированный граф:

```text
Manifest YAML
     ↓ validate / lock
Исполняемый граф
     ↓
Node → Port → Edge → Node
```

Узел выполняет вычисление, порт определяет контракт данных, ребро выбирает
политику очереди и транспорт. Провайдеры добавляют интеграции, не связывая ядро
с ROS 2, компьютерным зрением или конкретным устройством.

## Наблюдаемость

Runtime явно показывает копирования, потери кадров, очереди, рестарты, выбранный
backend, CPU, память и состояние внешних приложений.

## Совместимость

Манифест и Provider API версионируются отдельно от внутренних реализаций. Это
позволяет постепенно переносить критические блоки из Python в C++ без изменения
пользовательского pipeline.
