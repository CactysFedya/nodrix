# Nodrix 1.9.0

Nodrix 1.9.0 turns existing execution plans, probes, telemetry, and benchmark
artifacts into a single explainable optimization workflow.

## Commands

- `nodrix plan` — static rates, memory, hardware and backend decisions;
- `nodrix diagnose` — evidence-backed findings from a measured run;
- `nodrix explain` — value, source, reason and rejected alternatives;
- `nodrix optimize` — separate candidate variants with optional benchmarks.

Unknown performance stays unknown until measured. Auto-tuning never edits or
applies a production manifest.
