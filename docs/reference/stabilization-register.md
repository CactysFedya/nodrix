# 2.3 beta stabilization register

This register separates delivered changes from backlog. Release notes must not
describe a backlog item as implemented.

## Delivered in 2.3.0b1

- Stable local file-module identity and regression tests.
- Release metadata consistency and repository URL correction.
- Bilingual principles, release, deployment, and integration docs.
- Documentation validation for release-critical pages.
- Honest Raspberry Pi 5 hardware-smoke evidence.

- Confirmed metric-map persistence.
- Duplicate Livox process diagnosis.

- Endurance evidence and performance measurements.
